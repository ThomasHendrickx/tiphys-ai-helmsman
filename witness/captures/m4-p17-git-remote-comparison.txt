M4-P17 FIX ROUND 1 appended the blocks below, taken the same day on the
same git, over the same fixture with one remote-tracking ref added to it.
The `%(refname:short)` block is the defect in one line: git renders
refs/remotes/origin/HEAD short as `origin`, so a filter testing for a
`/HEAD` suffix over that rendering never fires. The `%(refname)%09%(symref)`
blocks are what the corrected check reads; the TAB is present on every row
and the symref field is empty for a ref that is not symbolic.
