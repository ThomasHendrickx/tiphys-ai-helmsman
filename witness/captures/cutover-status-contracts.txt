# captured 2026-09-18 with git version 2.43.0 and GNU grep 3.11
#
# The two external programs `tiphys cutover status` spawns and PARSES.
#
#   1. git for-each-ref --format=%(refname:short) --no-merged <upstream>
#      refs/remotes/origin, whose STDOUT is the informational branch count.
#   2. sh -c <a retirement row's negative-witness command>, whose EXIT STATUS
#      is half of the ported verdict.
#
# Every block below is a real run. The named test
# `the captured status contracts this phase parses are reproduced live`
# re-runs each of them in a scratch repository and requires the live exit
# status to equal the one recorded here, so none of these is a hand-written
# string chosen to match the implementation.
#
# THE TWO FACTS THAT EARN THEIR PLACE. An empty stdout with exit 0 is what
# makes "no unmerged branch" decidable, and it is why an upstream that does not
# resolve has to be a THIRD answer rather than a zero: that case exits 128, not
# 0 with an empty list. And grep distinguishes 1 (searched, found nothing) from
# 2 (could not search), which is why a negative witness is required to match
# the exit its row recorded rather than merely to be nonzero.
