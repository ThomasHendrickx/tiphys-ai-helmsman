M6-P4: the real stdout of the gate runner over fixture registries that
declare an optional run parameter.

Captured 2026-09-30 in the kernel container on node v26.6.0
(/home/user/.toolchains/node-v26.6.0-linux-x64/bin/node), git 2.43.0. Each block is
the runner's stdout from the command above it, byte for byte except three
substitutions that are declared here: the first line (`gates: run <random id>`)
is dropped; the fixture's base commit is written <base> (40 hex digits) or
<base12> (its first 12), because it changes with every commit time; and the
suite child's node version is written <node>, because it is the version of
whichever toolchain runs the test. The fixtures are built exactly as
test/criteria.test.ts builds them. Nothing below is hand-written; the named
tests reproduce each block live, apply the same substitutions, and compare it
with assert.equal.

WHY THIS FILE EXISTS. Red-witness rule (f) binds witnesses whose members touch
src/gates/run.ts or src/gates/suite.ts, because both spawn another program and
judge what it reports. What the runner passed and what the gate made of it is
the contract, so the contract is the runner's output.
