### Step 4's verification-before-editing, as the step requires

The step says to verify the runner's option-parsing shape before editing and
to consume any selection M2 already provides. M2 provides `--only <id>`, a
repeated flag matching exact gate ids (`src/commands/gates.ts` pushes each
value; `src/gates/run.ts` filters with `only.includes(id)`). It provides NO
document-shape selection and NO mode selection, so both flags are new. `--only`
is CONSUMED rather than duplicated: it composes with `--registry`, and the
criterion-3c and diff-scoped evidence below both use `--registry ... --only`
together.

### Declared design decisions inside step 4, with their reasons

1. **`--registry` and `--manifest` are separate flags and are mutually
   exclusive.** A single `--manifest` that inferred the document's shape from
   its contents or its extension would be "deciding what a document is by
   pattern-matching it", which MECHANISMS.md forbids and which the runner's own
   header already refuses for gate parameters. Two source documents in one run
   is refused rather than resolved, because an ambiguous run's summary would
   name a document that governed half of it.
2. **The registry is PROJECTED onto an M2 `GateManifest` and the M2 runner is
   not otherwise touched.** This is the whole anti-hazard device of the phase.
   `makeGateResult`, `ingestGateRun`, `runOneGate`, `decideAggregate` are
   reached identically from both flags, so M2-C-2 and M2-C-3 apply to registry
   runs BY CONSTRUCTION rather than by being remembered. Criteria 3b and 3c
   below are the executions that prove it.
3. **The projection is validated AGAIN, by `validateManifestDocument`.** The
   claim "the registry is a superset of the manifest" is turned into a check:
   a projection the M2 schema refuses means the registry is not a superset,
   and the run refuses instead of proceeding.
4. **An unknown `--mode` is a refusal, not an empty run.** A mode no entry
   declares would select nothing, and a run of nothing exiting 0 is the vacuous
   pass this registry exists to prevent (M2-C-3, fail closed). The refusal
   names the declared modes.

- `conditional` is precisely the declaration that a gate MAY report
