### AXIS 2, COST: what a correctness-only measurement would have missed (T-012)

T-012 is explicit that a measurement checking correctness and not cost is not a
partial answer but a wrong one, and that the omission is invisible when the
non-coverage section does not name performance. So, named:

- **The universal-quantifier pattern** is measured above on a long near-miss:
  flat to 256,001 characters. This is the only new pattern with an alternation.
- **The negative-lookahead branch** `^(?:(?!\b(...)\b)[\s\S])*$` is the
  expensive shape in the diff and is included in the same measurement, because
  it is what runs on every accepted `analysis`.
- **`report-parity-arithmetic`** is O(gate results) with constant work each.
  **`final-report-finding-parity`** builds two maps and is O(inputs + rows); it
  is not the O(n squared) nested scan a naive orphan check would be.
- **The companion change costs one extra `ajv.addSchema` per compilation of a
  companion-needing type**, and compilations are cached per (schema, companion
  list) pair, so the cost is paid once per process. Measured indirectly: the
  full suite went from a captured 507 reported tests to 535 with no timeout
  change, and the `suite` gate run completed in 2 minutes 51 seconds before
  this phase's tests existed.
- **NOT MEASURED**: I did not measure `pattern: "\\S"` on a pathological
  subject, because a single-character class with no quantifier cannot backtrack.
  That is a reading, not a measurement, and it is stated as one.

### AXIS 3, FAILURE MODE: what happens when each new guard is wrong

- A companion declared for a type whose schema has no cross-document reference:
  harmless, one wasted `addSchema`.
- A companion NOT declared for a type whose schema does have one: compilation
  fails closed with `unresolvedRef`, and `tiphys validate` exits 1 with a
  diagnostic. It cannot pass silently.
- `report-parity-arithmetic` on a gate result with a non-integer count: returns
  without a violation, because the schema has already rejected it. If the check
  is ever run on an unvalidated instance, this is a silent pass, and it is a
  deliberate belt rather than the guard.
- `final-report-finding-parity` on a document where `inputs` is absent: the
  array is empty, no violation is emitted, and the schema's `required` is what
  rejects it. Witnessed: `tiphys validate` runs derived checks only AFTER schema
  validation succeeds (src/commands/validate.ts:285), so an instance missing
  `inputs` never reaches the check. Same shape.
- **The failure mode I could not close**: a finding dropped from BOTH `inputs`
  and `input-findings`. The two arrays then agree with each other and no
  comparison between them can see it. `src/gates/coverage.ts` answers this with
  a config-stated `expectedUnits` anchor (CR-986); nothing in the plan states
  such an anchor for the final report, so there is none here.

## Key decisions, with the why that is invisible in the diff

1. **Declared companion table rather than load-time bundling.** Bundling the
   shared definitions into the work-history document would also satisfy "the
   same definition object", but by a caching accident: the identity would come
   from a memoised parse rather than from there being one physical definition.
   The declared table keeps DR-0013 clause 4's real property, which is that the
   set of documents a schema may reach is declared in one auditable place and is
   never derived from the reference itself. Witnessed at
   test/work-history.test.ts:180, where the same document compiled with no
   declared companion fails closed.
2. **Relative `$ref` rather than absolute.** `report.schema.json#/$defs/claim`
   resolves against the referring document's `$id`. An absolute
   `https://tiphys.dev/...` form would resolve identically and would be
   classified as REMOTE by `src/validate.ts:642` on any failure path, which
   would make a genuine mistake read as an attempted network fetch.
3. **The derived checks are wider than their criteria.** Both converses and the
   duplicate case are checked. A criterion names one direction of a relation; a
   guard narrower than its own description is what this project keeps
   re-buying, and M2-P6 paid for both of these extra directions by measurement
   (CR-985, CR-988) rather than by argument.
4. **No new derived check for the missing `no-findings-statement`.** Section
   2.3's table is the auditable list and D-M3-22 makes an unlisted row a plan
   defect to escalate. Escalated, not written.
5. **No `witness/` spec files.** The witnessing this phase's criteria prescribe
   is keyword removal and check deregistration inside the tests, which the
   `witness/` spec format (a `find`/`replace` mutation of a source file) does
   not express for a JSON schema keyword. T-011 is the reason not to reach for
   it lightly: a `find` string is a literal coupling to source text.

### `enumerate-shared-defs.mjs` (CR-001)

```javascript
/*
 * M3-P4 fix round 2, CR-001 derivation.
 *
 * Enumerate every `$def` shared between two or more shipped schemas, every
 * derived check that guards it, and whether that check runs on every artifact
 * type that reaches the definition.
 *
 * Scope: every file matched by `git ls-files 'schemas/*.json'`, and every
 * check in the src/checks.ts registry. Both are read from disk, so this is a
 * derivation over the shipped artifacts rather than over a hand-written list.
 */
import { readFileSync } from "node:fs";
import { execSync } from "node:child_process";

const root = process.argv[2] ?? process.cwd();
const files = execSync("git ls-files 'schemas/*.json'", { cwd: root, encoding: "utf8" })
  .trim()
  .split("\n")
  .filter(Boolean);

const checks = (await import(new URL("file://" + root + "/src/checks.ts").href));
const registry = checks.registeredChecks();

/** Walk a decoded schema and yield every `$ref` with the path that reached it. */
function* refs(node, path) {
  if (Array.isArray(node)) {
    for (let i = 0; i < node.length; i += 1) yield* refs(node[i], [...path, String(i)]);
    return;
  }
  if (node === null || typeof node !== "object") return;
  for (const [key, value] of Object.entries(node)) {
    if (key === "$ref" && typeof value === "string") {
      yield { ref: value, path };
      continue;
    }
    yield* refs(value, [...path, key]);
  }
}

/* type name per schema file, taken from the document's own `kind` const so
   nothing here is hand-mapped. */
const typeOf = new Map();
const decoded = new Map();
for (const file of files) {
  const doc = JSON.parse(readFileSync(root + "/" + file, "utf8"));
  decoded.set(file, doc);
  const kind = doc?.properties?.kind?.const;
  typeOf.set(file, typeof kind === "string" ? kind : "(no kind const)");
}

/* definition pointer -> { owner, users: Map<type, paths[]> } */
const shared = new Map();
for (const file of files) {
  for (const { ref, path } of refs(decoded.get(file), [])) {
    if (ref.startsWith("#/")) continue; // local, never crosses a document
    const key = ref;
    const entry = shared.get(key) ?? { owner: key.split("#")[0], users: new Map() };
    const type = typeOf.get(file);
    const at = entry.users.get(type) ?? [];
    at.push("/" + path.join("/"));
    entry.users.set(type, at);
    shared.set(key, entry);
  }
}
/* The OWNING document uses its own definitions too, by a local `#/$defs/...`
   reference; add those users so a check registered only for the borrower is
   also visible. */
for (const [pointer, entry] of shared) {
  const ownerFile = "schemas/" + entry.owner;
  if (!decoded.has(ownerFile)) throw new Error("owner not in scope: " + ownerFile);
  const localPointer = pointer.slice(pointer.indexOf("#"));
  for (const { ref, path } of refs(decoded.get(ownerFile), [])) {
    if (ref !== localPointer) continue;
    const type = typeOf.get(ownerFile);
    const at = entry.users.get(type) ?? [];
    at.push("/" + path.join("/"));
    entry.users.set(type, at);
  }
}

console.log("SCHEMA FILES EXAMINED (git ls-files 'schemas/*.json'):");
for (const file of files) console.log("  " + file + "   kind=" + typeOf.get(file));
console.log("");
console.log("REGISTERED DERIVED CHECKS (src/checks.ts registry):");
for (const check of registry) {
  console.log(
    "  " +
      check.id.padEnd(38) +
      " types=[" +
      checks.typesOf(check).join(", ") +
      "]  guards=[" +
      (check.guards ?? []).join(", ") +
      "]",
  );
}
console.log("");
console.log("CROSS-DOCUMENT $defs, THEIR USERS, AND THE CHECKS THAT GUARD THEM:");
if (shared.size === 0) console.log("  (none)");
let holes = 0;
for (const [pointer, entry] of [...shared.entries()].sort()) {
  const users = [...entry.users.keys()].sort();
  console.log("");
  console.log("  " + pointer);
  for (const type of users) {
    console.log("      used by type " + type + " at " + entry.users.get(type).join(", "));
  }
  const guards = registry.filter((c) => (c.guards ?? []).includes(pointer));
  if (guards.length === 0) {
    console.log("      guarded by: NO DERIVED CHECK (keyword-only definition)");
    continue;
  }
  for (const check of guards) {
    const runsOn = checks.typesOf(check);
    const missing = users.filter((t) => !runsOn.includes(t));
    console.log(
      "      guarded by: " +
        check.id +
        " runs on [" +
        runsOn.join(", ") +
        "] -> " +
        (missing.length === 0 ? "COVERS EVERY USER" : "HOLE, does not run on " + missing.join(", ")),
    );
    if (missing.length > 0) holes += 1;
  }
}
console.log("");
console.log("HOLES FOUND: " + holes);
process.exit(holes === 0 ? 0 : 1);
```
